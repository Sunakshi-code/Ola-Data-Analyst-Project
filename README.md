# Ola Data Analyst Project

## Project Overview
This project analyzes Ola ride-booking data using MySQL and Power BI. Both tools use the same dataset to explore booking trends, cancellations, ride performance, create Measures, and business insights.

## Project Objectives
- Analyze ride-booking data using MySQL.
- Solve 10 business questions using MySQL queries.
- Create an interactive Power BI dashboard.
- Analyze booking trends and cancellation patterns.
- Create Measures.
- Present meaningful insights to support data-driven decisions.

## Tools & Technologies
- **MySQL:** Data querying and analysis
- **Power BI:** Data visualization and dashboard development
- **Dataset:** Ola ride-booking data

## Project Structure
- `Dataset/` — Source dataset
- `MySQL/` — MySQL queries for 10 business questions
- `Power-BI/` — Power BI report and dashboard screenshots

## Project Components

### 1. MySQL Analysis
Contains 10 business questions and their MySQL queries to explore the dataset and identify useful insights.

### 2. Power BI Dashboard
An interactive dashboard built using the same dataset to visualize key performance indicators, booking trends, and cancellation patterns.

## Key Insights

- **Booking Performance:** Analyzed successful, cancelled, and incomplete bookings to understand overall ride-booking performance.
- **Ride Distance Analysis:** Evaluated average ride distance by vehicle type and identified the top 5 vehicle types based on total ride distance.
- **Cancellation Analysis:** Examined customer cancellations and driver cancellations caused by personal or car-related issues to understand cancellation patterns.
- **Customer Behavior:** Identified the top 5 customers by number of rides booked and analyzed the top customers by total booking value.
- **Ratings Analysis:** Compared average customer ratings across vehicle types, examined driver rating ranges for Prime Sedan bookings, and analyzed customer versus driver ratings.
- **Revenue Analysis:** Calculated the total booking value of successfully completed rides and analyzed revenue distribution by payment method.
- **Payment Preferences:** Analyzed UPI transactions to understand payment-method usage.
- **Incomplete Ride Analysis:** Investigated incomplete rides and their recorded reasons.
- **Time-Based Analysis:** Visualized ride volume over time and ride-distance distribution by day to explore booking trends.
- **Interactive Dashboard:** Developed a Power BI dashboard to present booking status, ride distance, cancellations, revenue, customer behavior, and ratings through visualizations.

## Conclusion

This project combines MySQL and Power BI to analyze Ola ride-booking data. MySQL was used to answer 10 business questions through queries, while Power BI was used to build an interactive dashboard addressing 10 analytical requirements. Together, these tools helped organize the data into meaningful business metrics and visual insights.
